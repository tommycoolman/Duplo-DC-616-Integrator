# Duplo-DC-616-Integrator
Integrate the Duplo DC-616 with Fiery Command Workstation/Imposer

The Windows executable and the *.pyw file are functionally the same, but the *.pyw file needs the Python Interpreter installed.  I use the Microsoft Store to install Python.  The *.pyw extension is a Windows convention -- it allows you to double-click on the file to run it while suppressing the console window.
